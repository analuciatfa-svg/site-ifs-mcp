Simulações reais via MCP

As mesmas jornadas de dados da aba “Simulações Reais”, agora roteadas pelo Salesforce Platform MCP — o servidor MCP hospedado pela própria Salesforce (headless-360), não o MuleSoft Agent Fabric. O handshake e cada chamada acontecem ao vivo na somaOrg: OAuth → initialize → discover → describe → dispatch → dados reais. O segredo do app fica só no servidor; o navegador nunca o vê.

● AO VIVO chamada real ao MCP + dados reais da org ○ CURADO o MCP roteia só rotas curadas (GraphQL sim; SOQL cru e Apex REST custom → não)

Honestidade técnica: o Salesforce Platform MCP é um roteador curado, não um proxy de API cru. A rota /services/data/vXX/graphql é roteável (lê e grava Lead/Case/Opportunity via UIAPI); SOQL cru (/query?q=) e Apex REST custom retornam ROUTE_NOT_FOUND — por isso as jornadas de dados aqui vão por GraphQL, não por redirect. Autenticação: OAuth 2.0 client_credentials por um External Client App; o token tem escopo mcp_api. Este painel fala com a ponte local (http://localhost:8795), que mantém o segredo no servidor. As conversas (chat do app) seguem no Agentforce via MIAW — não passam pelo MCP.
