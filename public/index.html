Simulações reais via MCP

Idênticas às da aba anterior, mas o caminho até a org passa pelo Salesforce Platform MCP — o servidor MCP hospedado pela própria Salesforce (headless-360), não o MuleSoft Agent Fabric. Cada jornada roda o protocolo de verdade na somaOrg: OAuth → initialize → discover → describe → dispatch → dados reais. O segredo do app fica só no servidor (a ponte); o navegador nunca vê token.

🔌 Ver o handshake ao vivo: abre o painel que acende cada passo do MCP e lista os registros reais (Lead / Opportunity / Case) que o dispatch de GraphQL trouxe da org. Honestidade: o MCP é um roteador curado — GraphQL é roteável (lê e grava); SOQL cru e Apex REST custom retornam ROUTE_NOT_FOUND. As conversas (chat do app) seguem no Agentforce via MIAW, fora do MCP.
